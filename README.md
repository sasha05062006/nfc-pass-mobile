# NFC Pass Mobile

Android-приложение для диагностики NFC-пропусков (турникеты и т.п.) на Samsung Galaxy S20+.

## Возможности (минимальная версия)

- Сканирование NFC-карт через Android NFC API
- Отображение реально доступных данных (технологии, UID, NDEF и т.д.)
- Анализ совместимости (почему карту нельзя просто эмулировать)
- Диагностика NFC на устройстве
- Русский интерфейс, Material Design 3
- Локальное хранение (базовая версия)

## Сборка APK без компьютера

1. Зайдите в репозиторий → вкладка **Actions**
2. Выберите workflow **Build APK**
3. Нажмите **Run workflow** → **Run workflow**
4. Дождитесь окончания сборки (3–8 минут)
5. Внизу страницы run скачайте артефакт `app-debug`
6. Распакуйте и установите `app-debug.apk` на телефон (разрешите установку из неизвестных источников)

## Требования

- Android 8.0+
- NFC-модуль
- Samsung Galaxy S20+ (и другие устройства с NFC)

## Безопасность

Приложение **не** реализует подбор ключей, клонирование защищённых карт или обход авторизации.
Чтение только открытых данных.
