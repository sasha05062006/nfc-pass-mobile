# NFC Pass Mobile

Android-приложение для диагностики NFC-карт и пропусков на Samsung Galaxy S20+ и других Android-устройствах с NFC.

## Что умеет первая версия

- Обнаруживает поддерживаемые NFC-карты через Android Reader Mode.
- Показывает UID, доступные NFC-технологии и доступные NDEF-данные.
- Сохраняет историю сканирований локально на телефоне.
- Показывает базовые ограничения совместимости.

## Как получить APK только с телефона

1. Открой вкладку **Actions**: https://github.com/sasha05062006/nfc-pass-mobile/actions
2. Выбери workflow **Build Android APK**.
3. Нажми **Run workflow** → **Run workflow**.
4. Открой последний запуск и дождись статуса **Success**.
5. В разделе **Artifacts** скачай ZIP **nfc-pass-debug-apk**.
6. Открой ZIP в «Мои файлы» и извлеки `app-debug.apk`.
7. Нажми на APK и разреши установку для используемого файлового менеджера, если Android попросит.

Workflow также запускается автоматически после изменений в исходниках на ветке `main`.

## Важно знать

- Приложение читает только данные, которые предоставляет Android и сама карта.
- Обнаружение UID **не** означает, что карту можно клонировать или что телефон сможет заменить её на турникете.
- Обычный NFC телефона работает на 13,56 МГц; RFID-карты 125 кГц стандартный NFC-модуль телефона не читает.
- Защищённые пропуска требуют официальной поддержки мобильного доступа со стороны организации.
- Это отладочный APK, а не релизная сборка для Google Play.

## Технологии

Kotlin, Jetpack Compose, Android NFC API, Android SDK 35, Gradle 8.9, Java 17.
